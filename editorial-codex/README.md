# Editorial Codex

Prototipo visual de una librería online, hecho con HTML, CSS y JavaScript nativos.

**Ver online:** https://alucrecia-pagano.github.io/Prototipos-Frontend/

Incluye catálogo, búsqueda y filtros, escritores, detalles de libros, temas claro/oscuro y formularios de demostración. Las compras y las cuentas son simuladas; no se guardan contraseñas.

## Tecnologías

- HTML, CSS y JavaScript nativos, sin librerías ni frameworks
- Diseño responsive (de 320 px a escritorio) y tema claro/oscuro
- Accesibilidad: navegación con teclado, foco visible y respeto por `prefers-reduced-motion`

## Cómo probarlo

Abrí `index.html` en un navegador: no requiere instalación ni conexión a servicios externos. Probá ambos temas, el sidebar expandido y colapsado, la navegación con teclado y los carruseles, que se desplazan al acercar el cursor a sus bordes. Con movimiento reducido se desactivan ese comportamiento y las animaciones decorativas.

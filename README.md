# Prototipos Frontend

Proyectos de frontend de Amanda Pagano, estudiante de la Tecnicatura Universitaria en Programación (UTN FRM).

## Proyectos

### [Editorial Codex](editorial-codex/)
Prototipo visual de una librería online con HTML, CSS y JavaScript nativos: catálogo, búsqueda, filtros y tema claro/oscuro.
**Ver online:** https://alucrecia-pagano.github.io/Prototipos-Frontend/editorial-codex/

### [Food Store — Autenticación](foodstore-auth/)
Registro, login y protección de rutas por rol con Vite, TypeScript y localStorage. Interfaz oscura con portadas fotográficas.
Para probarlo: `cd foodstore-auth`, `npm install` y `npm run dev`.
